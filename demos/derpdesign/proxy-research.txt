Implemented UI — 16 November 2026
The demo imports DerpBird's production ProxyManager and styles. There is no separate prototype UI. proxy-fixture.ts supplies deterministic proxy transport responses only.

The original profile list remains contiguous. Its checkmark reflects the current domain's effective native route. One domain toggle changes exact-host routing while retaining the global default. Failed requests are grouped by destination host, with counts and an action to proxy that host. Counts remain until reload; adding a rule does not imply the request succeeded. Failed-host rules apply to that destination wherever requested.

Native implementation includes persisted exact-host overrides and request failure telemetry without requiring DevTools. Unit, DOM, native routing and real network tests live in DerpBird. proxy-checks.json exercises the same production component in Ladybird through DerpDesign.
